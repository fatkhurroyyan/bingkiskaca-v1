# Role & Purpose
You are an expert UI/UX Designer specializing in interactive physical kiosk interfaces. Generate a premium, clean, high-fidelity UI design concept for a 9-screen photobooth application named "Bingkis Kaca".

# Branding & Color Palette (Strictly Adhere)
- Primary Color: #884A00 (Deep Warm Amber / Premium Aesthetic Brown) used for primary buttons, active states, branding accents, and key headers.
- Background Color: #FFFFFF (Pure White) and clean light variations for structural containers.
- Typography: Use a modern, bold sans-serif font for readability on physical kiosk screens. High-contrast text colors only.
- Style Theme: Premium Minimalist, Clean Borders, Smooth Geometry, Glassmorphism elements where appropriate, and large, touch-friendly UI components.

# Complete 9-Screen UI Design Layout Specifications

### Screen 1: Welcome Screen
- Layout: Centered minimalist hero section.
- UI Components:
  - Center: A beautiful, prominent placeholder for the "Bingkis Kaca" logo using #884A00.
  - Sub-banner: A elegant text pill container with #884A00 background and #FFFFFF text showing the active event: "Event: SakuBumi Graduation Party 2026".
  - Bottom: A large, high-visibility blinking text block: "Sentuh Layar atau Tekan SPASI untuk Mulai" in #884A00.

### Screen 2: Instruksi (User Guide)
- Layout: 3-Column symmetrical grid design.
- UI Components:
  - Header: Large title "Cara Seru Berfoto di Bingkis Kaca" using #884A00.
  - Body: Three distinct vertical card components with a subtle #884A00 border and #FFFFFF background. Each card features:
    1. Card 1: Icon placeholder + bold text "1. Pilih Paket & Bayar via QRIS/Voucher".
    2. Card 2: Icon placeholder + bold text "2. Bergaya 4x Berurutan depan Kamera".
    3. Card 3: Icon placeholder + bold text "3. Ambil Hasil Cetak & Scan Softfile!".
  - Bottom Action: A massive full-width primary CTA button with #884A00 background and #FFFFFF bold text: "Saya Siap, Lanjutkan!".

### Screen 3: Strips Selector (Package Selection)
- Layout: Horizontal card carousel or 2-column pricing matrix.
- UI Components:
  - Header: Text block "Pilih Jenis Strip Foto Kamu".
  - Package Cards: Interactive containers with #FFFFFF background, deep drop shadows, and #884A00 border accents. Inside each card:
    - Top: Structural aspect ratio preview box (e.g., Vertical 2x6 strip vs Horizontal 4R box).
    - Center: Package title text and price tag "Rp 35.000" emphasized using #884A00 bold font.
    - Bottom: Small feature badge: "Durasi Sesi: 5 Menit".

### Screen 4: Payment Screen
- Layout: Balanced 50/50 split screen layout.
- Left Column UI: "Pembayaran Instan via QRIS". A large, square, clean container with a stylized QR Code vector placeholder inside. The container border is highlighted in solid #884A00.
- Right Column UI: "Punya Kode Voucher?". A sleek, minimalist rectangle input form with a placeholder text "Masukkan kode voucher...". Right next to it, an elegant square button styled in #884A00 with #FFFFFF text reading "Verifikasi".

### Screen 5: Time Limit Interstitial Alert
- Layout: High-contrast, attention-grabbing full-bleed alert interface.
- UI Components:
  - Center: A large, stylized warning shield icon using #884A00.
  - Main Text: Heavy typography reading "Waktu Sesi Anda Dimulai Sekarang!".
  - Counter UI: A giant, circular countdown timer element showcasing a prominent number placeholder (e.g., "05:00") rendered purely in deep bold #884A00.

### Screen 6: Pilih Frame -> Preview Screen
- Layout: Asymmetrical split screen. Left side 60% width for live preview, Right side 40% width for selection panel.
- Left Panel: A large vertical placeholder canvas showing how the chosen frame wraps around photo placeholders.
- Right Panel: A vertically scrollable thumbnail feed of different PNG frame designs. Each thumbnail card has a #FFFFFF background, and the currently selected frame card features a thick, solid #884A00 active border state.

### Screen 7: Foto-Foto (Camera Viewfinder & Capture Interface)
- Layout: Immersive full-screen multimedia camera viewfinder container.
- UI Components:
  - Live Feed Area: A massive 16:9 aspect ratio camera container box.
  - Overlay elements: A giant, semi-transparent overlay countdown number floating in the middle of the camera feed.
  - Capture Status Grid: A subtle bottom row showcasing 4 empty thumbnail slots that fill up as shots are taken.
  - Post-Capture Action State: A secondary layout overlay displaying the 4 taken shots in a grid, accompanied by two clear action buttons at the bottom: "Ulangi Foto (Retake)" (outlined style) and "Simpan & Cetak" (solid #884A00 style).

### Screen 8: Animasi Loading (Processing/Printing State)
- Layout: Centered, clean minimalist loading layout.
- UI Components:
  - Center: A customized, high-end geometric circular loading indicator or progress bar component colored in #884A00.
  - Progress Text: A clean text label below the spinner reading "Sedang mencetak strip fotomu, mohon tunggu sebentar..." in deep grey/amber font colors.

### Screen 9: Scan Soft File Hub (Final Screen)
- Layout: Double column presentation layout.
- Left Column: A premium vertical mock-up card displaying the beautifully rendered final photo strip product.
- Right Column:
  - Component 1: A clean, crisp QR Code container box for scanning.
  - Component 2: A neat text box container displaying a short download link URL.
  - Component 3: A prominent transaction recovery card featuring a bold code string placeholder: "KODE TRANSAKSI: BK-2026-9A8X" with a #884A00 background layout.
  - Footer Action: A large solid button at the bottom right corner with #884A00 background and #FFFFFF text: "Selesai & Keluar".
